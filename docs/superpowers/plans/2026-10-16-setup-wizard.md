# Setup Wizard Implementation Plan

> **For agentic workers:** Use subagent-driven-development for independent tasks, with root integration and independent validation.

**Goal:** Deliver the approved project-aware devcontainer wizard with persistent preferences and optional Codespaces launch.

**Architecture:** A thin Bash bootstrap invokes a Python standard-library package. Gum handles terminal interaction; detection, rendering, Git transactions, and GitHub operations have separate modules. Rendering returns a reviewable mapping of relative paths to bytes before any target changes occur.

**Tech Stack:** Python 3.11+, Bash, Gum, Git, GitHub CLI, Dev Containers CLI, go-task, unittest.

## Global constraints

- Python and `uv` are always included for agent scratch work as well as projects.
- Dotfiles application and coding-agent tools initially default to Yes.
- Personal preferences use `${XDG_CONFIG_HOME:-$HOME/.config}/devcontainer-setup/config.json`.
- Scan repository files as data; ignore patterns alone never select a runtime.
- Preserve project work; review exact generated bytes before committing; never force push or merge diverged histories.
- Consumer projects receive only selected standard configuration/helpers, not the wizard implementation.
- Final confirmation names commit and, when chosen, push/resource creation/open actions.
- Run red/green tests before committing each owned change. No model attribution in commits.

## Shared interfaces

`discovery.scan(project: Path) -> dict` returns `runtimes` (python/node/ruby/go/rust entries containing `selected`, `version`, `evidence`, `conflicts`), `tools` (entries containing `selected`, `evidence`), `ports`, `package_managers`, and `warnings`.

`preferences.load_preferences(env: Mapping | None = None) -> dict` and `save_preferences(values: dict, env: Mapping | None = None) -> Path` handle XDG data and validation; `preferences.config_path(env=None) -> Path` exposes the actual location.

`render.render(project: Path, source: Path, selections: dict, source_ref: str) -> dict[str, bytes]` generates a candidate without changing the checkout. Selections contain `runtimes` (name to version), `tools` (list of bundle names), `agents`, `dotfiles`, `ssh`, `ports`, `package_managers`, and optional `polyglot`. No dotfiles repository is passed to rendering. Rendering raises `ValueError` for unsafe conflicts. `render.validate(project: Path) -> list[str]` returns errors for a generated project.
